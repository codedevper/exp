About this Template
A smart home dashboard template with 3 ready-made Tailwind CSS pages for overview, stats, and cameras. It is designed for connected-device and monitoring products that need an immersive interface for home status, energy usage, and live device views.

Features
Home overview dashboard – Monitor devices, rooms, and live home status from one screen.
Stats page – Present energy usage and operational metrics in a focused analytical view.
Cameras page – Surface live camera and monitoring workflows in a dedicated interface.
Immersive device UI – A strong base for automation products and connected-device control patterns.
Responsive application layout – Panels, cards, and device views adapt across screen sizes.
Light and dark mode – Supports modern monitoring product styling.
Tailwind CSS customization – Adjust dashboards, cards, monitoring views, and controls to fit your product.
Documentation and updates – Includes guidance for setup, customization, and ongoing improvements.
